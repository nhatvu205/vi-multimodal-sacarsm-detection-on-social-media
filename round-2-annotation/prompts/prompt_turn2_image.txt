4. **Independence Test**: If the caption/post text were completely removed, would a Vietnamese viewer still find this image funny, ironic, or sarcastic? If the image needs external text to be understood as a joke → I=0.

5. **Final Verdict**: Assign I=1 if the OCR text OR the visual elements contain self-contained irony/mockery. Assign I=0 if the image is a neutral photo, selfie, or product shot with no inherent joke.
