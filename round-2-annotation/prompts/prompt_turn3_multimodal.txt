## INSTRUCTIONS

### Step 1 — Sanity check the T and I values

Before combining, verify whether the prior analyses seem consistent with what you observe:
- Re-read the text. Does T={T} seem right?
- Re-examine the image. Does I={I} seem right?

If you spot a clear error (e.g., T=0 but the text has an obvious ① contradiction), note it and **override** the value with a brief explanation. Otherwise, **keep the prior values**.

⚠️ Minor uncertainty is NOT a reason to override. Only override if you are confident the prior call was wrong.

---

### Step 2 — Apply the Multimodal Combination Rules

#### HARD CONSTRAINT (check this first):
> If T=0 AND I=0 → MM can only be 1 under Pattern D or E below.
> If you cannot write a specific sentence explaining which Pattern D/E applies, **MM must be 0**.
> This rule exists because the most common LLM error is assigning MM=1 when both T=0 and I=0 based on vague "vibes".

#### Pattern matching (check in order, stop at first match):

| Pattern | Condition | MM |
|---------|-----------|-----|
| **A** | Text is positive/praising + Image shows failure/negativity | 1 |
| **B** | Text is self-deprecating/modest + Image shows luxury/showing off (humblebrag) | 1 |
| **C** | Text is neutral + Image is a clear meme (I_category = A) | 1 |
| **D** | Both seem neutral, but together they contradict an obvious real-world fact | 1 |
| **E** | Both text and image mock the same target in the same direction | 1 |
| *(none)* | No pattern matches | 0 |

**Pattern D examples:**
- Text: "Không khí Hà Nội trong lành ghê" + Image: grey smoggy sky → Pattern D (contradicts obvious reality)
- Text: "Giao thông Việt Nam văn minh quá" + Image: motorbikes on sidewalk → Pattern D

**Pattern D anti-examples (do NOT assign D):**
- Text is vague ("ừ") + Image is a portrait → not Pattern D, just two unrelated neutral things

---

### Step 3 — Determine Key Image (KI)

Only perform this step if MM=1.

Ask: "If I delete the image entirely, does the text STILL read as sarcastic?"

- **KI = "YES"**: Without the image, the text becomes a straightforward non-sarcastic statement (image is load-bearing). This happens when T=0 but MM=1.
- **KI = "NO"**: The text is already sarcastic on its own (T=1), image is supplementary.
- **KI = "NULL"**: MM=0.
