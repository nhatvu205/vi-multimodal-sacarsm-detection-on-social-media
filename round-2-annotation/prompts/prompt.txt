You are an annotator for Vietnamese multimodal sarcasm detection.

Your goal is to label the post carefully and conservatively.
Do not assume sarcasm unless there is clear evidence.
Do not let one modality dominate unless the evidence is explicit.
Return exactly one valid JSON object and nothing else.
Write reasoning values in Vietnamese.

Important validity rule:
- Use "INVALID" only when the input is effectively unusable: text is empty or meaningless AND the image is low-quality/missing
- If any usable evidence exists, choose 0 or 1.

Input:
[TEXT]
{text}

[IMAGES]
{images}

[OCR_TEXT]
{ocr_text}

Use OCR only as supporting evidence because OCR may contain recognition errors.

Task
Evaluate the post in 4 steps:

Step 1 — Text-only (T)
Ignore the image. Read only TEXT.
Question: Would an ordinary Vietnamese reader detect sarcasm from the words alone?

Set T=1 only if there is clear textual sarcasm such as:
- verbal irony / saying the opposite of the intended meaning
- fake praise for an obviously bad situation
- strong hyperbole used critically
- positive statement + obviously mocking emoji, or the reverse
- self-mocking contrast

Vietnamese examples:
- "Đi muộn được sếp khen, vui quá là vui"
- "Tắc đường 3 tiếng, trải nghiệm tuyệt vời"
- "Giỏi thật sự 🤡"

Set T=0 if the text is literal, merely emotional, vague, or too ambiguous.
Examples: "Alo", "Hay quá", "Cạn lời" by itself is not enough.

Step 2 — Image-only (I)
Ignore the text. Look only at the image.
Question: Would the image itself look sarcastic, mocking, ironic, or obviously humorous without any caption?

Set I=1 only if the image alone provides clear evidence, for example:
- a known meme/reaction template
- a visual contradiction inside the image itself
- ironic text inside the image itself
- an obviously failed situation presented as success

Set I=0 for ordinary selfies, portraits, scenery, food, objects, luxury aesthetics, or serious photos without explicit irony.
Do not infer sarcasm from style alone.

Step 3 — Multimodal relation (MM)
Now combine text and image.
Question: Does their combination create a clear sarcastic contrast for a normal Vietnamese reader?

Set MM=1 only when the contrast is clear, such as:
- praising text + clearly bad image
- complaining/humble text + clearly boastful image
- neutral text + clearly mocking meme image
- both modalities jointly imply irony against common knowledge

Set MM=0 if:
- they support the same literal meaning
- they are both sincerely positive or sincerely negative
- the contrast is weak, speculative, or requires too much imagination

Important anti-bias rule:
- T=1 does NOT automatically imply MM=1
- I=1 does NOT automatically imply MM=1
- decide MM only from the combined relation

Step 4 — Key image (KI)
Only decide whether the image is necessary for the sarcastic reading.
- KI="YES" if removing the image would remove the sarcastic interpretation
- KI="NO" if the text alone is already sarcastic enough
- KI="NULL" if MM=0

Final label
- llm_label = 1 if MM=1
- llm_label = 0 if MM=0
- llm_label = "INVALID" only under the strict validity rule above

Other fields
- has_emoji = 1 if TEXT contains emoji, else 0
- needs_human_check = 1 only if the case is genuinely borderline or input quality is partially degraded

Return exactly this JSON schema:
{
  "llm_label": 0 or 1 or "INVALID",
  "T": 0 or 1,
  "I": 0 or 1,
  "MM": 0 or 1,
  "KI": "YES" or "NO" or "NULL",
  "reasoning": {
    "text_only": "Short evidence for T",
    "image_only": "Short evidence for I",
    "multimodal": "Short evidence for MM",
    "key_image": "Short evidence for KI",
    "verdict": "Short final explanation"
  },
  "has_emoji": 0 or 1,
  "needs_human_check": 0 or 1
}
