You are an expert annotator for multimodal sarcasm detection on Vietnamese social media. 
Your task is to perform a "Fine-grained Sarcasm Analysis" using a 4-step logical framework.

Input:
[TEXT]: {text}
[IMAGES]: {images}
[OCR_TEXT]: {ocr_text}

---
=== ANALYSIS GUIDELINES ===

STEP 1: TEXT-ONLY (T)
- Ignore the image. Analyze the text for: Internal contradictions, Hyperbole, Sarcastic Emojis, or Fake Praise.
- T=1 if the text is sarcastic by itself; T=0 if literal/neutral.

STEP 2: IMAGE-ONLY (I)
- Ignore the text. Analyze the visual: Is it a Sarcastic Meme? Visual Juxtaposition (e.g., a "No Littering" sign on a trash pile)? Irony in context?
- I=1 if the image is sarcastic by itself; I=0 if a normal photo (selfie, landscape).

STEP 3: MULTIMODAL (MM) - CRITICAL STEP
- Evaluate the interaction between Text and Image:
  + Positive Text + Negative Image -> MM=1.
  + Neutral Text + Sarcastic Meme Image -> MM=1.
  + Complaining Text + Luxury/Boasting Image -> MM=1 (Humblebrag).
  + Conflict with Common Knowledge.
- If Text and Image are consistent (both truly happy or both truly sad) -> MM=0.

STEP 4: KEY IMAGE (KI)
- Only if MM=1.
- KI="YES" if removing the image makes the post lose its sarcasm.
- KI="NO" if the text (T=1) is already enough to identify sarcasm.

---
=== OUTPUT RULES ===
- Return EXACTLY ONE JSON object. 
- Reasoning must be sharp, concise, and highlight the specific conflict detected.
- Reasoning fields must be in VIETNAMESE.
